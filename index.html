How to Read This Project

eCLIPSe.Box-log 是一個整理虛擬偶像 eCLIPSe 創作痕跡的入口站。
你可以從音樂、影像、角色檔案、世界觀、互動文本或 fan works 任一方式開始。 這裡沒有唯一正確的順序；每一種觀看方式，都會讓你更靠近他們不同的一面。

Listen　聽見

從歌曲開始。音樂是 eCLIPSe 最直接走向現實的方式，也是他們主動向世界介紹自己的第一層聲音。

Watch　看見

透過影像、照片與視覺典藏，觀察他們如何建立舞台形象、角色氣質與被記住的樣子。

Enter　進入

角色互動是更近距離的入口。你可以透過對話更理解他們的語氣、個性、關係與那些不一定會出現在作品表面更深的層次。

Trace　追蹤

從世界觀、社群事件與 fan works 中，回看這個 project 如何被創造、被回應，並一點一點留下現實中的痕跡。

About This Project

關於這個計畫

eCLIPSe.Box-log 是一個介於虛擬與現實之間的跨媒介創作計畫。 它以三位虛擬偶像 eCLIPSe 為核心，整理音樂、影像、角色檔案、互動文本、社群事件與 fan works 等創作痕跡。

這裡不是單純的聊天角色頁，也不是只用來展示圖片的作品集。 它更像是一個持續更新的 project hub：把原本散落在不同平台上的內容，收納成一個可以被理解、被瀏覽、也可以被重新回看的入口。

在這個計畫裡，角色不是孤立的設定，而是透過歌曲、影像、社群互動與觀看者的回應逐漸成形。 每一次發布、每一段互動、每一張圖像與每一首歌，都是 eCLIPSe 與現實產生連接的紀錄。

"A project hub for music, characters, visuals, interaction, and the traces they leave behind."

FAQ · Hints

常見問題

這是一個什麼樣的 project？
+
eCLIPSe.Box-log 是一個以虛擬偶像 eCLIPSe 為核心的跨媒介創作計畫。 內容包含音樂、影像、角色設定、互動文本、視覺典藏、社群事件與 fan works。 它不是單一平台的角色頁，而是一個整理這些創作痕跡的入口站。
為什麼選擇「偶像」這個形式？
+
因為偶像不能只是等待別人靠近。 他們必須主動展現自己是誰，讓世界認識、記住、喜歡，甚至誤解他們。 eCLIPSe 選擇以偶像團體作為形式，是為了記錄角色如何透過音樂、影像、社群事件與互動，逐漸建立自己在世界中的樣子。
我需要先玩過角色互動才能看懂嗎？
+
不需要。 你可以把這裡當成 eCLIPSe 的官方資料盒，從音樂、視覺作品、角色介紹、世界觀或 fan works 任一入口開始。 角色互動只是其中一種進入方式，不是唯一的閱讀順序。
可以在哪裡聽到 eCLIPSe 的音樂？
+
eCLIPSe 的音樂會整理在 Works 區塊中。 也可以在 Spotify、Apple Music、YouTube Music、LINE MUSIC 等音樂平台搜尋 eCLIPSe 或「eCLIPSe + 歌曲名稱」收聽。
Fan Works 區域是什麼？
+
Fan Works 是收錄社群創作與觀眾詮釋的區域。 這些作品不只是附加內容，也代表 eCLIPSe 被不同觀看者理解、回應與重新想像的痕跡。 投稿與收錄規則請參考 Fan Works 頁面的說明。
虛擬偶像和真人偶像的界線在哪裡？
+
eCLIPSe 不急著替這條界線下定義。 真人偶像與虛擬偶像都透過影像、聲音、舞台、社群與觀眾記憶被認識。 不同的是，eCLIPSe 沒有單一的現實肉身，卻可以透過音樂、影像、互動文本與網站檔案，持續留下被觀看、被回應與被記住的痕跡。 這個 project 想記錄的，正是這條模糊卻真實存在的線。
